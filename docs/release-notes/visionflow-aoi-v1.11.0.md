# VisionFlow AOI v1.11.0

Windows x64 版本，包含完整 `VisionFlow AOI` PyInstaller 資料夾與 CUDA `sm_86` DLL。這一版著重在上機測試：一次帶回所有設備狀態、自動找出光源協定，以及讓相機直連監控不會空等或檢測暗影像。

## 一鍵設備自檢

- CCD 頁最上方新增「設備自檢」（管理模式）。按一次就檢查相機、米輪、Sensor I/O（PCIe-1730）與光源，每項一行 `PASS／WARN／FAIL／SKIP`，並附總結行，例如 `C:PASS M:PASS D:WARN L:FAIL`。
- 相機未連線時執行 S1–S8 診斷並帶回數字短碼；已連線時列出狀態與 Frame Trigger 輸入。
- 米輪會連線並讀 Encoder／Compare，「自動遞增」為 0 時會提示；Sensor I/O 讀一次 Sensor DI；光源會列出本機 COM port，已設定時只開關 COM port，未設定時自動偵測協定。
- 自檢只讀取狀態：不開燈、不送 DO 脈衝、不改設定。報告存到 `outputs/logs/device_check/`，上機時拍下或抄回總結行即可。

## 光源協定自動偵測

- 光源面板新增「自動偵測」與「協定範本」（管理模式）。不知道控制器協定時，選好 COM port 按「自動偵測」，程式會以常見光源協定（CCS、OPT、SA、Modbus RTU）與 Baud rate 逐一探測；探測只送讀取或把通道 1 設為 0 的指令，不會開燈。
- 辨識到回覆就把設定填入表單（不自動保存），按「套用光源設定」後再按「開燈」確認燈有亮。控制器不回話時，可從「協定範本」逐一套用試亮；偵測不到時會列出格式不認得的回覆，方便判斷協定。
- 亮度指令範本新增 `{crc16}`（Modbus CRC）。光源仍連線時不能偵測，請先關燈。

## 相機直連監控

- 按「啟動」時，相機若還沒開始收觸發會自動開始（外部觸發開始預覽、軟體觸發開始監控），停止時一併停止；在 CCD 頁手動開始的預覽保持不變。
- 啟用光源時先開燈，控制器回覆成功後才開始收影像。光源無法使用、未設定指令或開燈失敗時，監控直接停止並顯示原因，避免暗影像被判為 NG。
- 停止監控時等擷取中的影像收完（最多 10 秒）再關燈。

## 驗證與限制

- 完整自動測試、語法編譯、CUDA 靜態預檢及 GUI 離屏啟動通過；設備自檢、光源偵測與監控啟動以模擬裝置測試。
- 內建的光源協定來自公開的常見協定格式，尚未在 SAT-24W350-R1、BTRS-ATHC-48W600-1T 上實測；相機、米輪、Sensor I/O 與光源都仍須在相機機台確認。本機沒有真實產品影像，不能代替現場驗收。
- CUDA source、C ABI 與檢測流程未改動；CPU fallback 與 Recipe 格式維持 v1.10.1 語意。

完整解壓縮 ZIP 後執行 `VisionFlow AOI.exe`，請勿只複製 EXE。
