# VisionFlow AOI v1.10.1

這是 v1.10.0 的 Windows x64 修正版，包含完整 `VisionFlow AOI` PyInstaller 資料夾與 CUDA `sm_86` DLL。光源控制、Sensor 中繼及其他 v1.10.0 功能維持原有設定與操作方式。

## 從原機台程式匯入

- CCD 頁現在可選擇 `.sln`、`.csproj` 或 C# 原始碼資料夾。掃描在背景執行，畫面會顯示「分析中…」，完成前不可重複啟動。
- 大型原始碼的值追蹤使用索引與快取，並為每次追蹤設定步數上限。超過上限的值會顯示為不完整，不能被當作已確定值自動套用。
- 找不到設定、讀取失敗或確認表無法開啟時會顯示原因，意外錯誤也會寫入 log。確認表仍須由管理者勾選後才套用，選取原程式不會執行它。

## 驗證與限制

- 以 `xx_ccd` 的 40 個 C# 原始檔掃描約 1.3 秒；完整 1106 項自動測試、語法編譯、CUDA 靜態預檢及 GUI 離屏啟動通過。
- 光源、Sensor 中繼與匯入結果仍須在相機機台依實際程式版本和硬體確認。本機沒有真實產品影像，不能代替現場驗收。
- CUDA source、C ABI 與檢測流程未改動；CPU fallback 與 Recipe 格式維持 v1.10.0 語意。

完整解壓縮 ZIP 後執行 `VisionFlow AOI.exe`，請勿只複製 EXE。
