# VisionFlow AOI 設備參數對照表（現場用）

這份表格把**原廠程式（原機台程式、LSI-8181 原廠工具）裡看到的參數**，對到 **VisionFlow 畫面上的位置**。上機時開著原廠程式的設定視窗，一列一列對照填入即可。

**現場確認（2026-09-30）**：使用者回報本輪設備功能測試皆通過，包含相機直連監控成功。相機取像、米輪線觸發、Sensor 軟體觸發、光源開關與 Recipe 相機設定已通過基本串聯測試。請保存目前成功的機台設定與產品 Recipe；以下 8000 行／每行 9 格等數值是這次產品的例子，不是所有產品的固定參數。最終 CMP_OUT 極性未回報，本表不推定為 10 或 2。

- 畫面名稱都在左側導覽列：**監控模式**、**CCD 控制**、**Recipe 設計**。
- 除了標示「工程模式可用」的欄位，其他都要切到**管理模式**才能修改。
- 錯誤訊息前面的 `[E-xxxx]` 代碼，對照同一個資料夾的 `ERROR_CODES.md`。

---

## 1. 米輪（LSI-8181）

位置：**CCD 控制 → 米輪（LSI-8181）** 面板。改完按該列右邊的「設定」或「套用」，米輪連線中會立即寫入。這些都是**機台設定**，每台機台存一份，不跟 Recipe 走。

| 原廠程式的名稱 | VisionFlow 欄位 | 說明 |
| --- | --- | --- |
| Card ID | 面板上方的卡片 ID 選單 → 「連線」 | 選好再按連線；程式啟動約 1 秒後會自動連線。 |
| Compare increment／自動遞增 | **自動遞增** → 套用 | 每幾格米輪拍一行。你的產品：每行 9 格就填 9。不能是 0。 |
| Multiple rate（x1／x2／x4） | **倍頻** | 下拉選單，選完立即寫入。 |
| 計數方向（反向） | **方向 → 反向計數** 勾選框 | Encoder 往下數時勾選。Sensor 取像中偵測到倒退，程式會自動切換並跳 `E-6108`。 |
| **CMP out width** | **CMP Out Width** → 設定 | **不能是 0**（0 時擷取卡收不到線觸發）。你的機台：**10**。 |
| **CMP output polarity** | **CMP OUT 極性** → 設定 | 原廠顯示 **10** 時，先確認是十進位數字還是兩個位元（1、0）；二進位 `10` 的十進位值是 **2**。這次現場已完整出圖，請沿用並保存實測成功值；最終數值未回報，不推定為 10 或 2。 |
| CMP output（勾選） | 不用設定 | VisionFlow 連線米輪時一律啟用 CMP output。 |
| Compare mode（auto） | 不用設定 | VisionFlow 固定使用 auto（自動遞增），與原廠一致。 |
| 計數模式、防抖 | 不用設定 | VisionFlow 固定為正交計數、1 µs 防抖；原廠不同時，智慧匯入會列警告。 |
| Encoder Set 值 | **Encoder** → 設定 | 也是外部觸發「同時寫入已存 Encoder 值」用的值。 |
| Compare Set 值 | **Compare** → 設定 | 也是外部觸發「自動寫入已存 Compare 值」用的值。 |
| CMP0–CMP7（Offset、脈寬、輸出點、Mask） | **CCD 控制 → Extension Compare（CMP0–CMP7）** → 套用 CMP0–CMP7 | 原廠有用到才需要設定。 |

## 2. 相機（Sapera／擷取卡）

位置：**CCD 控制 → 相機設定** 面板。改完按「**套用相機設定**」，相機連線中會自動重新連線寫入。

### 2-1 每個產品不同的參數：存在 Recipe

曝光、增益、影像長度、觸發方式會**跟著 Recipe 走**。設定方式：

1. 在 **CCD 控制 → 相機設定** 改好，按「套用相機設定」。
2. 到 **Recipe 設計**，按「**儲存 Recipe**」。這一步沒做，換 Recipe 後設定就不見了。
3. 換產品時載入該產品的 Recipe，到**監控模式**按「啟動」，程式會依 Recipe 自動連線／重連相機再開始取像。

| 原廠程式的名稱 | VisionFlow 欄位（取像參數／觸發） | 說明 |
| --- | --- | --- |
| Exposure／ExposureTime | **曝光時間** | |
| Gain | **增益** | |
| Length／CROP_HEIGHT | **影像長度（線）** | 你的產品：8000 行。米輪要走「長度 × 自動遞增」格才拍完一張（8000 × 9 = 72000 格）。 |
| Internal Line Rate | **內部線速率（Hz）** | 只在連續取像時用。 |
| Trigger Mode | **觸發模式** | 原程式由 Sensor 起拍、米輪出每一行 → 選「**軟體觸發**」。相機直連監控不能用「連續取像」。 |
| External Trigger One Frame | **外部觸發單張（External Trigger One Frame）** | 只在外部觸發模式可勾。 |
| Compare from encoder／Set encoder on trigger | **外部觸發時自動寫入已存 Compare 值**、**同時寫入已存 Encoder 值** | 只在外部觸發單張時有效。 |
| Auto save | **自動存圖** 兩個勾選框 | 相機直連監控的原圖開關在 **設定 → 輸出 → 相機直連保存原圖**（預設開啟），通常不需再勾快照自動存圖。關閉監控原圖時，本欄的自動快照仍獨立生效。 |

### 2-2 機台共用的參數：存在機台設定

| 原廠程式的名稱 | VisionFlow 欄位 | 說明 |
| --- | --- | --- |
| Server、Resource index、CCF 檔 | **Sapera 位置**（擷取伺服器、Resource Index、CCF 檔案）→ 「選擇 Sapera 位置…」 | 只找到一張擷取卡時會自動選取。 |
| 存圖資料夾、格式 | **CCD 控制 → 存圖** → 套用存圖設定 | 相機直連原圖採用此格式，但路徑固定在本次分析目錄 `origin/`。 |

相機直連保存原圖會與分析併行執行，PASS／NG／分析 ERROR 均保存；監控停止會等已收到影像的分析與原圖寫入完成。原圖開關保存於 GUI 設定，監控停止後才能更改。檢測佇列滿時另保留最多一張待存 ERROR 原圖；暫存也滿或磁碟寫入失敗時，結果帶 `raw_image_error`，需查看 log。v2.0.0 起包含此開關與 `origin/` 路徑；既有 v1.11.7 使用固定 `raw/` 路徑。

## 3. Sensor（PCIe-1730 I/O 卡）

位置：**CCD 控制 → Sensor 中繼（PCIe-1730）** 面板。改完按「**套用 Sensor 中繼設定**」。機台設定，不跟 Recipe 走。**原機台程式開著時不能用**（兩個程式搶同一張卡）。

| 原廠程式的名稱 | VisionFlow 欄位 | 說明 |
| --- | --- | --- |
| 裝置（例如 PCIe-1730,BID#0） | **I/O 卡裝置** | |
| Sensor 的 DI port／bit | **Sensor DI** → port、bit、低電位有效 | 按「讀取 DI」，遮住 Sensor 前後各讀一次，狀態要改變。 |
| 給擷取卡的 DO port／bit | **擷取卡 DO** → port、bit、低電位有效 | 只在外部觸發單張模式用到。 |
| DO 脈衝時間 | **DO 脈寬（ms）** | |
| Sensor 抖動保護 | **最短觸發間隔（ms）** | 間隔內的重複觸發視為抖動。 |
| — | **DI 讀取間隔（ms）** | 越小反應越快、越吃 CPU。 |
| 每次觸發把 Encoder 歸零 | **軟體觸發起拍 → 每次觸發先把 Encoder 設為**（勾選＋數值） | 原程式每次 Sensor 觸發會重設 Encoder 時才勾。 |
| 觸發後幾格才開始拍 | **起拍偏移（格）** | 0 表示下一格就開始拍。可按「帶入米輪 Encoder／Compare Set 值」自動填入。 |
| Automation.BDaq4.dll 位置 | **DAQNavi DLL** → 瀏覽 | 預設會自動找。 |
| 啟用 | **啟用 Sensor 中繼** 勾選框 | 要勾，程式才會轉送 Sensor。 |

## 4. 光源（RS-232）

位置：**CCD 控制 → 光源（RS-232）** 面板。改完按「**套用光源設定**」。機台設定。**原機台程式開著時不能用**（COM port 同時只能一個程式開）。

| 原廠程式的名稱 | VisionFlow 欄位 | 說明 |
| --- | --- | --- |
| COM port、Baud rate、Data bits、Parity、Stop bits | 同名欄位 | 智慧匯入會帶入。 |
| 指令結尾（CR／LF） | **指令結尾** | |
| 開燈指令 | **開燈指令** | 很多控制器沒有獨立開燈指令，靠送亮度就會亮，這時留空即可。 |
| 關燈指令 | **關燈指令** | 關燈時會先送這裡的指令，再把每個通道亮度設為 0。 |
| 設定亮度的指令 | **亮度指令範本** | 例如 `SA{value:04}#`；`{channel}` 是通道、`{value}` 是亮度。 |
| 亮度範圍 | **亮度上限** | 你的控制器：255。 |
| 通道 | **通道** | 例如 `1` 或 `1,2`。 |
| 亮度 | **目標亮度** → 「儲存並送出亮度」 | **工程模式可用**。「開燈」會用這裡的數值；全部是 0 時燈不會亮。 |
| 監控時自動開關燈 | **啟用光源控制** 勾選框 | 勾選後，監控開始時開燈、停止時關燈。 |

找不到正確指令時：按「**逐一試亮**」，每一組開燈後看燈有沒有亮，亮了就按「**有亮**」，那一組會直接存成光源設定。

## 5. 從原機台程式匯入（智慧匯入）

位置：**CCD 控制 → 從原機台程式匯入（智能模式）** → 「選擇原程式 .sln…」。

- 確認表會列出原程式的值、VisionFlow 目前的值與出處。標「可套用」的會預先勾選；「可能」的要你確認後再勾。
- 「**原程式參數總表**」列出原程式呼叫的每個 LSI8181 函式（含 CMP_OUT 極性、脈寬）與 Sapera 參數；標**警告**的是 VisionFlow 還沒對應或和原程式不同的地方。
- 「**Sensor 觸發流程**」列出原程式讀到 Sensor 後依序做的事；有 Encoder 歸零／Compare 起點時，可套用到「軟體觸發起拍」。

## 6. 建議上機順序

1. 關閉原機台程式（到工作管理員確認已結束）。
2. **CCD 控制 → 設備自檢 → 快速狀態檢查**，抄下總結行，例如 `C:PASS M:PASS D:PASS L:WARN`。
3. 對照本表第 1 節設定米輪，特別是 **CMP Out Width** 與 **CMP OUT 極性**。
4. 對照第 2 節設定相機，按「套用相機設定」，再到 **Recipe 設計 → 儲存 Recipe**。
5. 對照第 3、4 節設定 Sensor 與光源；光源按「開燈」、「關燈」各確認一次。
6. 到**監控模式**，來源選「**相機直連**」，按「**啟動**」，讓產品連續通過。
7. 有錯誤時，抄下訊息裡的代碼與括號內的數值（例如 E-6107 的 Encoder、Compare、擷取卡讀回）回報。
