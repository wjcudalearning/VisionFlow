# AOI CV Based 流水帳報告

日期：2026-08-06（星期四）至 2026-08-12（星期三）

本週主要工作集中在新增 Detector 202 凸多邊形檢測、逐圖缺陷 CSV 自動彙總、單張結果大量 Overlay 的 GUI 穩定性，以及兩次 Windows CUDA-enabled 發行。期間共完成 8 筆功能／文件提交，異動 22 個檔案，累計新增 1,449 行、刪除 145 行；完整測試套件由 207 項增加至 228 項。週期末主線版本為 VisionFlow AOI v1.3.1 之後的修正版；GitHub 上的 v1.3.0 與 v1.3.1 均已正式發布。

## 2026-08-06（星期四）

- 新增 Detector 202 凸多邊形 NG 檢測，整合 DetectorManager、Recipe Designer 繁中標籤、結果 metadata、cached shared `PreprocessPlan`、resident ROI 安全路由及 CPU／CUDA fallback。
- Detector 202 依面積、近似 epsilon、頂點數與凸性篩選輪廓，命中任一符合條件的凸多邊形即判定為 NG；首版加入後完整測試由 207 項增加至 218 項。
- 正式發布 VisionFlow AOI v1.3.0 Windows x64 CUDA-enabled 版本，發行內容加入 Detector 202；GitHub Release 為非草稿、非 prerelease。
- 新增逐圖缺陷 CSV 自動彙總。單張與批次分析完成後，以及監控模式 Stop 且背景執行緒停止後，會將同一執行目錄 `csv/` 的逐圖 CSV 合併為 UTF-8 BOM `summary.csv`。
- CSV 合併會排除既有 summary、採來源欄位聯集並原子覆寫，避免重複累加、監控寫入競爭或留下半寫入檔案；實際 CLI 合成 NG smoke 產生 5 筆缺陷與 5 列 summary，完整測試增加至 223 項。
- 正式發布 VisionFlow AOI v1.3.1 Windows x64 CUDA-enabled 版本，將自動產生 `csv/summary.csv` 納入發行內容；GitHub Release 為非草稿、非 prerelease。
- 依排除屏蔽調參工具修正 Detector 202 的中心與邊緣屏蔽語意：中心 X=100、Y=630 改按半徑解讀，未裁切時實際屏蔽為 200×1260；另加入共同內縮、屏蔽開關、自訂中心與最多 12 頂點等契約。
- 修正單張檢測大量 Overlay 時偶發的畫面向下延伸、殘影與變形。`ImageViewer` 改為批次替換 overlay、暫停逐項 viewport update，再主動 invalidate／重繪。
- Results 頁改為實際開啟時才建立表格與輸出內容，NG 縮圖每批載入 24 張；350／1,000 個 overlay 的完成 callback 由約 0.58／2.00 秒降至約 0.033／0.076 秒，完整測試增加至 228 項。

- 同一張 400×1400 合成小圖直接呼叫調參工具函式逐像素比較，最終結果為 0 差異；中心 X／Y 半徑、共同內縮 0、左 15、右 26、上 50、下 20 也完全一致。

- 本次未修改 CUDA source、header、ABI 或 DLL，因此不需要重編 CUDA DLL，也沒有新增 RTX runtime 驗收結論。

## 本週重點整理

- GUI 大量 Overlay 與 Results 延後載入問題完成修正，1,000 個 overlay 的檢測完成 callback 約由 2.00 秒降至 0.076 秒。

- 完整測試套件由 207 項增加至 228 項；本週功能提交所記錄的 tests、compileall、CUDA source／ABI preflight、相關 CLI／GUI smoke 與 `git diff --check` 均通過。

## 版本差異與風險

- v1.3.0 tag 建立於 Detector 202 首版提交，v1.3.1 tag 建立於 CSV summary 提交；兩者都早於 8 月 6 日稍晚的屏蔽語意修正與 8 月 7 日的處理順序修正。
- 因此 GitHub 上 v1.3.0／v1.3.1 的 Detector 202 並不包含目前 `main` 已通過逐像素調參工具比對的最終行為。若正式使用 Detector 202，應以目前主線為準，並另行準備包含這兩項修正的新發行版。

## 尚待完成

- 建立包含 Detector 202 最終屏蔽語意與前處理順序的新 Windows 發行版，避免使用者誤以為 v1.3.1 已包含主線修正。
- 五份 production Recipe 仍需各補一張固定、可追溯的真實 PASS／NG 案例，完成正式量產資料驗收。
